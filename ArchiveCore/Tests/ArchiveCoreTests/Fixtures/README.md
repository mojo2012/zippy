The `.rar` files here are test archives from libarchive 3.8.11
(`libarchive/test/test_read_format_*.rar.uu` and `test_rar_multivolume_*.rar.uu`,
decoded with `uudecode`; the multi-volume sets are renamed to `*_multivolume.partN.rar`),
used under libarchive's BSD license (https://github.com/libarchive/libarchive/blob/master/COPYING).
No RAR tool is needed to create them.
